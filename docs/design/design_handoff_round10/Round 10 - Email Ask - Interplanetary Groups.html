The recommendation, in one line

B2. Bottom sheet at a 65% floor, with the X and Not now. Full screen removes the header the second ask sends people to, and the centred card is light enough that a member may treat it as dismissible noise on a first read. The sheet is heavy enough to be answered and cheap enough to be left.

Dismiss

Two exits, both labeled, neither teal. The X is a 44px circle on --surface-raised with a hairline border, so it is a control at a glance rather than a glyph floating in padding. Not now is a 17px underlined text control directly under Save, in --text-secondary. Underline plus position carries it, so it survives with colour switched off. Save is the only teal thing in the frame.

Both exits spend the ask, per the rule in the brief. Tapping the scrim or backing out does not.

Orbit's note

  • Grid, not a float. grid-template-columns: 34px 1fr, the mark spanning both rows in column one. Every line of copy shares a left edge; nothing wraps around the mark. This is the fix for the ragged indent in the shipped version.
  • Eyebrow reads A NOTE FROM ORBIT at --type-eyebrow 13px, letter-spacing: .14em, --text-secondary. It is vertically centred against the mark, so the two read as one line.
  • Copy at --type-body 17px, up from 15px. No bubble: bordered box on --surface-raised, which is the app's existing labeled-note grammar, and correct here because one person sees this and a bubble would imply the group can.
  • Lime appears only inside the mark, including its 9px glow. Nothing lime is tappable.

Fields

  • Both inputs are 1.0625rem (17px), above the 16px iOS zoom threshold. Min-height 52px on the email field, 60px on the code field.
  • Code field is one input, eight digits, JetBrains Mono at --type-title with .26em tracking and tabular figures. Paste works. No segmented boxes.
  • Save is --action on --action-ink with the existing top-lit gradient from the finish layer, min-height 52px, full width.

Growth

No fixed heights anywhere. The sheet's 65% is min-height; frame F shows it exceeded by longer copy. The full screen puts its spacer between the note and the field, so enlarged text eats the air first and the Save stays reachable. The card is content-height with an 18px side inset. Nothing clips.

One tension worth naming

Frame D carries a teal border because the brief asks for it, which is the one place teal appears on something that is not Save. It reads as a system callout rather than a control, and D is the version we are choosing against, so it does not set precedent. If the inline version were ever shipped, that border should be --hairline at 1.6px with the fill lifted instead.
