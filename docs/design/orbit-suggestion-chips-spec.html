Orbit spontaneous-suggestion reply chips

When Orbit proposes an event off a trigger (someone says "we should finally grab beers"), it posts a gauge message with three quick-reply chips. This is the isolated spec — the in-app version on Walkthrough · screen 07 is clipped by the fixed phone frame, so use this sheet for the labels, roles, and styling.

The three optionslabel · role · behavior
🍻 I'm in Yes Affirmative RSVP. Counts the member toward the threshold. The one emphasized chip (solid surface, full-strength text). Emoji: 🍻.
🙏 Next time No Declines this one without friction or guilt. Quiet styling (dimmer text + hairline border). Emoji: 🙏.
📅 Yes, can't Fri Yes, but not that date Willing, date doesn't work. Signals interest while rejecting the proposed day — Orbit can float an alternative. Quiet styling. Emoji: 📅.

Build notes

  • Container .gh-qr — display:flex; flex-wrap:wrap; gap:7px, indented under the message.
  • Chip .gh-qrchip — pill, 1.7px border --stroke-strong, bg --surface-raised, text --ink, size --type-label (14px), weight 600.
  • Secondary chips add .quiet — text --ink-soft, border --stroke. Only "I'm in" stays full-strength.
  • Never lime and never teal-filled — these are neutral outlined chips; the accent stays reserved for the event card's primary action.
